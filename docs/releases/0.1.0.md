# Morifolium v0.1.0

Morifolium v0.1.0 is the first bounded source-distribution release of the mobile platform engineering golden path.

## Supported reference profile

v0.1.0 ships one executable reference profile:

- native Android/Kotlin;
- Android Gradle Plugin 9.3.1;
- Android API 36 / build tools 36.0.0;
- Temurin Java 17 and Gradle 9.5.0 through `mise`;
- canonical local/CI entry point: `mise run ci`;
- debug APK output at `app/build/outputs/apk/debug/app-debug.apk`.

The release does not claim a KMP, React Native, native iOS, or production application architecture profile.

## Validation contract

The canonical gate runs one coordinated Gradle invocation for:

- Android lint/static analysis;
- JVM unit and conformance tests;
- security/configuration invariants;
- privacy-aware observability tests;
- debug APK assembly.

The reference fixture intentionally has no product UI/E2E workflow to validate. v0.1.0 does not add synthetic UI/E2E tests merely to populate a test pyramid layer.

## Security defaults

The Android reference profile includes:

- cleartext traffic denied by default;
- cloud backup and device-transfer data excluded by default;
- only the launcher activity exported;
- no production secrets, release signing keys, telemetry credentials, or remote endpoints in validation;
- read-only CI permissions;
- immutable pinning for the shared CI workflow.

These are reference-platform defaults, not a substitute for a consumer product threat model.

## Observability boundary

v0.1.0 includes a local, privacy-aware operational telemetry contract:

- low-cardinality operational events;
- metadata minimization before the sink boundary;
- an in-memory reference sink with no network export;
- optional sink failures contained so observability cannot change an independent domain result;
- cancellation, thread interruption, and JVM `Error` conditions remain exceptional and are not swallowed.

Remote exporters, analytics products, consent, retention, residency, and provider credentials remain consumer-owned.

## Distribution and upgrades

Morifolium is a versioned source distribution. Immutable Git tags and GitHub releases are the version authority.

The root `.morifolium-version` file is the authoritative source-lineage marker and now also supplies the Android reference application's `versionName`, removing the previous duplicated version string.

GitHub template mode remains deferred for v0.1.0. No package registry, binary publication, release-signing workflow, attestation layer, or automated migration tool is introduced by this release.

## Adoption evidence

Eyespie provides the second-consumer evidence for the project-level task boundary: an existing Kotlin Multiplatform application adopted the canonical `mise run ci` interface without replacing its product architecture, existing Gradle setup, security boundary, or observability choices.

This supports Morifolium's role as a project/SDLC composition contract rather than a shared application runtime.

## Migration

See [v0.1.0 migration and reconciliation guidance](../migrations/0.1.0.md).

Because v0.1.0 is the first immutable release, migration guidance primarily covers consumers that adopted pre-release Morifolium conventions or want to reconcile an existing mobile repository against the v0.1 contracts.
